==================================================
FEATURE: CHANNEL-BASED FILTERING
==================================================

Implement channel-specific filtering similar to the Facebook module.

When a YouTube channel is selected, ONLY data belonging to that selected channel should be displayed.

Apply this behavior consistently in ALL YouTube pages:

1. YouTube Scheduler
2. YouTube Bulk Upload
3. YouTube Automation

==================================================
YOUTUBE SCHEDULER
==================================================

After selecting a YouTube channel:

- Upload Queue should show only uploads for that channel.
- Pending tab should show only pending uploads for that channel.
- Posted/Published tab should show only uploaded videos for that channel.
- Failed tab should show only failed uploads for that channel.

Changing the selected channel should instantly refresh the list without reloading the page.

==================================================
YOUTUBE BULK UPLOAD
==================================================

After selecting a channel:

Display only that channel's:

- Pending uploads
- Completed uploads
- Failed uploads
- Queue

No videos from other channels should appear.

==================================================
YOUTUBE AUTOMATION
==================================================

Each automation is linked to a YouTube channel.

When viewing an automation:

Show only data belonging to that automation's selected YouTube channel, including:

- Pending Queue
- Uploaded Videos
- Failed Uploads
- Queue Statistics
- Upload History
- Facebook Sync Queue (if applicable)

==================================================
DATABASE
==================================================

Filter using the YouTube Channel ID (or the channel foreign key already stored in the database).

Do NOT filter by title or channel name.

==================================================
UI
==================================================

Display summary counts for the selected channel only:

Pending
Published
Failed
Total

Switching channels should immediately update all counters and lists.
