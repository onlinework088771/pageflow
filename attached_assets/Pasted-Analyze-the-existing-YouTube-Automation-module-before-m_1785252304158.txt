Analyze the existing YouTube Automation module before making any changes.

Redesign ONLY the YouTube Automation module into a professional, production-ready automation dashboard.

Do NOT modify or break any Facebook modules, YouTube Scheduler, Bulk Upload, OAuth, or existing working functionality.

==================================================
GOAL
==================================================

The YouTube Automation page should become the central dashboard for automatically uploading videos from external platforms (Facebook, Instagram, TikTok) to a selected YouTube channel.

The workflow must be clean, intuitive, modern, and easy to use on both desktop and mobile.

==================================================
STEP 1 — SELECT YOUTUBE CHANNEL
==================================================

At the top of the page, display all connected YouTube channels.

Allow the user to select one channel.

After selecting a channel, every automation created on this page belongs ONLY to that selected YouTube Channel.

Display:

• Channel avatar
• Channel name
• @Handle
• Subscriber count

Highlight the currently selected channel.

==================================================
STEP 2 — CREATE AUTOMATION
==================================================

Below the selected channel, show a "Create Automation" card.

User configures:

Source Platform

• Facebook
• Instagram
• TikTok

Depending on the selected source, display only the relevant input fields.

Example:

Facebook
→ Public Page URL / Username

Instagram
→ Username / Profile URL

TikTok
→ Username / Profile URL

==================================================
AUTOMATION SETTINGS
==================================================

Allow the user to configure:

• Automation Name
• Source
• Source URL
• Video Type
    - Shorts
    - Long Video
    - Both
• Upload Privacy
    - Public (default)
    - Unlisted
    - Private
• Upload Interval
• Start Time
• Timezone (default Asia/Dhaka)
• AI Title
    ON / OFF
• AI Description
    ON / OFF
• Auto Hashtags
    ON / OFF
• Auto Publish
    ON / OFF
